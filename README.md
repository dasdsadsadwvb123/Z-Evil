# Z-Evil

2D 像素生存恐怖游戏 · Unity 2022.3.62f3c1 + URP 2D · 个人独立开发

> 一名医生在休息日遭遇丧尸狗破窗而入，为取回留在医院的半辈子医学成果，逆着逃散的人流回到已经沦陷的医院。

**▶ 完整介绍、演示视频与截图请看作品集页：[Z-Evil-Portfolio](https://github.com/dasdsadsadwvb123/Z-Evil-Portfolio)**

## 这个仓库里是什么

- `Assets/` —— 游戏资源与**全部 C# 脚本**（脚本在 `Assets/Scripts/`）
- `Packages/`、`ProjectSettings/` —— Unity 工程配置

## 怎么打开

1. 用 Unity Hub 安装 **2022.3.62f3c1**
2. 用 Unity 打开本工程
3. 打开 `Assets/Scenes/Intro.unity` → 点击 Play

> 首次打开需要等 Unity 导入资源（几分钟）。`Intro` 是开场界面场景，按 Play 后点击画面即可开始。
